개인정보처리방침

CoverageManager (보장분석 관리) · 시행일 2026-10-22

1. 기본 원칙

CoverageManager(이하 '프로그램')는 사용자의 컴퓨터에서만 동작하는 프로그램입니다. 개발자는 별도의 서버를 운영하지 않으며, 사용자가 입력한 어떤 정보도 개발자에게 전송되거나 수집되지 않습니다.

2. 프로그램이 다루는 정보와 저장 위치

  • 사용자가 직접 입력한 고객 정보(이름, 연락처, 보험 가입 내역, 첨부 서류 등)는 사용자 컴퓨터의 프로그램 폴더(data)에 저장됩니다.
  • 이 정보는 사용자가 정한 비밀번호로 잠근(암호화한) 상태로 저장됩니다.

3. Google 사용자 데이터의 이용

사용자가 'Google 드라이브 연결'을 켠 경우에만 다음과 같이 Google 계정에 접근합니다.

  • 요청하는 권한: drive.file(프로그램이 만든 파일만), drive.appdata(프로그램 전용 숨김 폴더). 드라이브의 다른 파일은 읽거나 바꾸거나 지우지 않습니다.
  • 이용 목적: 사용자의 자료 사본을 사용자 본인의 Google 드라이브에 보관하고, 다른 컴퓨터에서 같은 자료를 불러오기 위해서만 씁니다.
  • 올리는 내용: 사용자의 비밀번호로 암호화된 자료 파일만 올립니다. Google과 개발자는 그 내용을 볼 수 없습니다.
  • 제3자 제공: Google 사용자 데이터를 개발자나 다른 누구에게도 전송·판매·공유하지 않으며, 광고에 쓰지 않습니다.
  • 로그인 정보: Google 접근 열쇠(토큰)는 사용자의 브라우저 안에만 잠시 보관되고, 개발자에게 전송되지 않습니다.

프로그램의 Google 사용자 데이터 이용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 연결 해제와 삭제

  • 프로그램의 환경설정에서 언제든 Google 드라이브 연결을 끊을 수 있습니다.
  • Google 계정 설정(myaccount.google.com/permissions)에서 프로그램의 접근 권한을 직접 없앨 수 있습니다.
  • 드라이브에 올린 자료는 사용자가 드라이브에서 직접 지울 수 있습니다.
